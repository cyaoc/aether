# 便携模式：数据放在程序旁边的 data/ 目录，不放系统应用数据目录

数据库和设置文件放在根目录下的 `data/` 子目录，没有放到系统规定的应用数据目录。这样做有两个目的：一是整个程序加数据可以直接拷走，二是开发时数据就在仓库里，随时能看到。

根目录这样确定：
- Release 构建：可执行文件所在目录。
- Debug 构建：从可执行文件所在目录往上找，找到 `Aether.slnx` 所在的目录就用它；找不到就退回可执行文件所在目录。

程序里不写死任何绝对路径。路径只由构建配置决定，跟当前工作目录无关。CLI 和 GUI 发布到同一个文件夹，就共用同一个 `data/`。

## Consequences

- `data/` 里有明文的登录凭据，所以必须加进 `.gitignore`。
- mac 的 `.app` 包内部不可写；从下载目录直接打开的应用，会被系统挪到随机的只读路径运行。Windows 的 `Program Files` 普通权限也写不进去。等做 `.app` 或安装包时，这条决策要重新讨论。
