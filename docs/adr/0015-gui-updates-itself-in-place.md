# GUI 打开时自己更新，原地换掉程序目录里的文件，不能回滚

有些主播不会手动升级（下载新的发布包、解压到新目录、复制 `data/`），一直用着旧版本。所以 GUI 每次打开时在启动页上检查 `cyaoc/aether` 的 GitHub Releases：有新版本，就下载和自己同一种的发布包（同平台，独立版或需运行时版）到程序目录下的 `.update/`，用 GitHub 给的 sha256 校验，解压，再把程序目录里要换掉的文件改名成 `.old`、把新文件移进去，然后重启进新版本。`data/` 不动，新版本打开时按 [ADR 0011](0011-data-upgrade-from-0-2-3.md) 自己升级。下载时可以跳过，先用当前版本；下载完就不能跳过了。CLI 不自动更新。

有人想一直留在当前版本，所以通用设置里有“打开时自动更新”开关，默认开，关掉就不检查。它存在 GUI 设置（`data/gui.yml`）里，但和页面上其他项一样，点“保存”才生效。（2026-11-07 起它在设置文件的 `auto_update.enabled`，见 [ADR 0016](0016-config-in-settings-file-and-database.md)。）

## Considered Options

- Velopack：mac 上要做成 `.app`，官方要求签名和公证；`data/` 要搬出程序目录，和 [ADR 0002](0002-portable-data-directory.md) 冲突，已有用户还得手动迁一次；发布流程要重写。没有选。等真做 `.app` 或安装包时再看。
- NetSparkle：按"下载安装包、运行安装包"设计，我们没有安装包，解压后换文件这一步它不管。没有选。
- 新版本解压到旁边的新目录，把 `data/` 复制过去：旧目录原样保留，能回滚；但桌面快捷方式还指向旧目录，下次打开的还是旧版本，目录和带着登录凭据的 `data/` 副本越积越多。没有选。
- 后台下载，下次打开时生效，侧栏提示"下次启动生效"：用户要的是打开时在启动页上一次做完、看得到进度。没有选。
- 发现新版本后让用户点按钮才更新：要照顾的正是不会主动升级的人，他们多半不点。改成默认更新、下载时给"跳过"。
- 不给开关，总是自动更新：想留在旧版本的人没有办法。没有选。
- 开关放进设置文件 `aether.yml`：CLI 读设置文件时会把缺的分组补写进去，用 CLI 的人会看到一个对 CLI 没用的 `update:`；按 ADR 0011，新设置的默认值改变效果时升级要写入旧效果，已有用户升级后就成了关，而他们正是要照顾的人。没有选。（2026-11-07 改为放进设置文件：第一条 ADR 0016 接受了；第二条，旧的效果取自 `gui.yml`，大多数人是开。）
- 开关一改就保存：通用设置页上其他项都要点“保存”，混进一个立即生效的项让人困惑。没有选。
- 由 `.update/` 里的新版本自己去覆盖程序目录：旧进程退出、新版本覆盖、再启动正式的新版本，窗口要闪两次。改成当前进程改名替换，只闪一次。

## Consequences

- 自动更新以后不能回滚：旧程序文件被换掉了，数据库升级以后旧版本也打不开。ADR 0011 说的"旧目录原样保留、直接运行旧程序"只对手动升级成立。不替用户备份 `data/`，和 ADR 0011 一致。
- 程序目录的名字还是解压时的旧版本号，里面装的是新版本。
- 第一个带自动更新的版本要手动装一次。
- 替换前不试跑新版本：试跑要同时开两个 `Aether.Gui`，还要求以后每个版本的试跑入口都不碰 `data/` 和 `.update/`；它能防的只有需运行时版缺 .NET，而需运行时版只要求 .NET 10 的某个版本，只有换 .NET 大版本时才会缺。到那时，需运行时版的用户自动更新以后会打不开，由 .NET 自己提示去装新的运行时（mac 上自动重启那一次看不到提示，要从 Finder 再打开一次）；那一版的 release 说明要提前写清楚。
- 开关不在设置文件里，“打开设置文件”改不了它；设置文件有错、整页不能保存时，它也跟着不能保存。`gui.yml` 读失败时回到默认值，也就是开。（2026-11-07 起开关在设置文件里，设置文件有错、值不能用时按默认值开，见 ADR 0016。）
- 正在运行的 exe、dll 在 Windows 上不能覆盖、可以改名，这是这套做法的前提，要在 Windows 上测过。
- 只替换和新增文件，旧版本多出来的文件留着；`.old` 和 `.update/` 由下次启动删掉。
- 安装途中断电或进程被杀，程序目录里会新旧混杂、可能打不开，只能重新解压发布包；`data/` 不受影响。
- 同一个程序目录里开着别的 GUI 进程时不更新，免得那个进程后面加载到新版本的文件。（2026-11-07 起一个 `data/` 同时只跑一个进程，这种情况不会再有，见 [ADR 0018](0018-one-process-per-data-directory.md)。）
- 检查用的是不登录的 GitHub API，每个 IP 每小时 60 次；查不到就当没有新版本。
- 下载先走 gh-proxy.org（在 GitHub 的下载地址前加 `https://gh-proxy.org/`），失败再直连 GitHub（#338）。检查不走代理：大小和 sha256 来自 GitHub，代理换不了文件。gh-proxy.org 是免费的第三方服务，挂了每次都多等一次失败再直连；换了域名就要发新版本改地址。代理和直连都慢时，下载可能要好几分钟。
- 仓库要是转成私有，不登录就查不到 Releases。转之前先发一个把检查地址改到新位置的版本，等用户都更新过去再转。
