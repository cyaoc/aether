# 隐藏款按投入发放，不做随机

隐藏款是观众送礼换来的限时进场动画。讨论里先后考虑过"送指定礼物按主播设的爆率抽"和"按盲盒开出的价值定档、亏损时随机给一款安慰"，两者都是付费换随机奖励。《网络主播行为规范》（广电总局、文旅部 2022）第十四条把"宣传'刷礼物抽奖'"列为主播不得出现的行为，情节严重的封号；后一种还奖励"开得大"、安慰"亏了"，诱导更强。所以隐藏款只按一轮送礼的投入给：投入够哪一阶就给哪一阶，同一阶里按固定顺序给下一款还没有的，Aether 这边不做任何随机。思路和 ADR 0008 一致：Aether 不提供和付费挂钩的随机。

## Considered Options

- **送指定礼物按爆率抽**：主播最初的想法，主播可定制礼物和爆率。正是规范点名的那一类。
- **按盲盒开出价值定档，亏损随机给安慰款**：随机由 B站 的盲盒产生，但等于给盲盒加了第二层奖励，奖励大额开出、安慰亏损。
- **按投入定档、档内固定顺序**（采用）：和舰长、提督、总督按价格分级同一个逻辑，花多少给什么；观众不知道顺序，拿到哪款仍有惊喜。

## Consequences

- 以后有人想在隐藏款里加概率、抽卡、保底之类的随机机制，先找 B站 官方确认规则，再推翻这条决定。
- 剩余天数不在直播画面上显示，避免变成催观众续费。
