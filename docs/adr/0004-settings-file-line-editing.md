# 设置文件只用"分组 → 单行值"，GUI 逐行改写，保留注释

设置文件 `data/aether.yml` 既给 CLI 用户手改，也给 GUI 的设置表单改。YamlDotNet 读写会丢掉注释，.NET 里也没有常用的保留注释的 YAML 库；按模板整份重新生成能留住模板注释，但会丢掉用户自己加的注释和不认识的键。所以 GUI 保存时只替换对应那一行冒号后面的值，其余内容原样保留。

为了让逐行改写可靠，设置文件只用一种形状：顶层是分组，分组下每个设置一行，值写在同一行里（列表用 `[a, b]` 的单行写法）。首次运行生成的模板把默认值写成生效的行，而不是注释掉；表单遇到缺失的项就插到所在分组末尾，缺失的分组追加到文件末尾。

## Consequences

- 以后加的设置（欢迎条件等）都要设计成这个形状。用户手改成多行写法或嵌套结构时，表单把该项设为只读，提示去设置文件里编辑。
- 默认值写进了文件，以后版本改默认值，已经生成的文件不会跟着变。
