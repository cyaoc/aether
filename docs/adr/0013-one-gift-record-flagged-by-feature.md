# 盲盒统计和礼物榜共用一份收礼记录，每条标明收到时谁开着

取代 [ADR 0012](0012-gift-board-stores-its-own-totals.md)。bot 连着直播间时收到的每份付费礼物只写一行收礼记录，盲盒统计和礼物榜都只读它，各按自己的规则算。每行标明盲盒统计要不要它、礼物榜把它算进了哪一期（盲盒统计看收到时它的开关，只要盲盒；礼物榜看收到时有没有一期在统计，见 [ADR 0014](0014-gift-board-runs-in-periods-like-a-lottery.md)），两个都不要就不写，每个功能只算带自己标记的行，所以没在记的时候收到的不算，开关拨过几次都一样。礼物榜不再存汇总行。汇总行带来的合并 SQL、单价取整丢零头、内存里记号去重和盲盒的两份记录都随之去掉。

## Considered Options

- 各存一份（ADR 0012）：礼物榜存按期汇总的行。清空、恢复要合并行，按平均单价累加会丢零头（审查实测），去重只能在内存里按直播间连接记。没有选。
- 一张表，任一开着就记，不加标记：开着一个、关着另一个的那段时间收到的礼物，打开另一个以后会被算进去，改变了开关的意思。没有选。
- 每个开关记一个开启时间，只算之后的：开关拨过一次，之前正常记下的也被排除（盲盒统计本月中途关一会儿再开，本月前几天的就不算了）；要算准得记下每段开关区间，查询更复杂。没有选。
- 定期清理旧记录：索引已经让查当前这一期不受旧记录影响，清理只省磁盘，估计一年不到 100 MB。不做。

## Consequences

- 数据库只升一个版本：v0.3.1 是 5，原定的 6（删 `raw_message`）和 7 都没发布，合成一个 6：建收礼记录和期两张表，把 `blind_box` 的全部行搬进收礼记录（标为盲盒统计开、礼物榜关），再删掉 `blind_box`。
- 盲盒统计按 B站 的送出时间切今日、本月；礼物榜的期不靠时间，每行直接记下它属于哪一期，同一时刻的礼物和换期也分得清。原先每期记开始前最后一条记录的号当分界线，但礼物先进内存、后写库，写库之前换了期，内存和库就会把这份礼物算进不同的期，所以改成每行带期号。
- 去重靠表上唯一的 `tid`（大航海是 `payflow_id`），跨重连、重启都有效。
- 礼物榜在连上直播间时把最新这一期分组相加一次，放在内存里，之后每来一份礼物先在内存里加上、推给画面，再写库；每来一份就重新相加，几个月的总榜到几万条时每份要几十毫秒，所以不这样做。写库失败时画面照常，没存下的礼物重新连接后不算；内存里记着这一期的 `tid`，重复推送不会因为写库失败而算两遍。
- 记录不清理：盲盒历史和旧的期全部保留。
