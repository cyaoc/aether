# 礼物榜自己存一份汇总，不和盲盒统计共用记录

> 已被 [ADR 0013](0013-one-gift-record-flagged-by-feature.md) 取代：盲盒统计和礼物榜共用一份收礼记录，每条标明收到时谁开着。

礼物榜按“期、观众、礼物”存汇总行，盲盒开出的礼物也算在里面，所以同一次开盲盒在 `blind_box`（盲盒统计）和礼物榜里各有一份。我们有意不合并：两个功能各有开关，礼物榜清空、换期、恢复上一期都不能影响盲盒统计；礼物榜要的头像、礼物图标也不在 `blind_box` 里。重复的只是盲盒那部分，而且礼物榜存的是汇总行，体积很小。

## Considered Options

- 礼物榜的盲盒部分改从 `blind_box` 读，自己只存普通礼物和大航海。要给 `blind_box` 加头像和图标两列并升级已有数据；盲盒记录要改成“盲盒统计和礼物榜任一个开着就记”，盲盒统计的意思也跟着变（关着时的盲盒也会算进今日、本月）；礼物榜每次显示都要把两张表合起来汇总，期只能按时间段切。没有选。
