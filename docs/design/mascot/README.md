# 看板娘新形象

2026-11-08 在对话里定稿，没有用设计稿画布，以本目录为准。讨论记录在 [#343](https://github.com/cyaoc/aether/issues/343)。
这里是一位新的看板娘：人设图、Q 版、启动页和登录页（都已拆成背景层和角色层）、礼物榜的两张姿势图，以及以后给她画图、拆层用的脚本。
把她换上去走以后的票，见 #343。

## 她是谁

| 项目 | 设定 |
|---|---|
| 人 | 成年女性，约 23 岁，168 cm，偏瘦但有运动感；立绘约 6.5–7 头身 |
| 性格 | 社恐、有点天然呆、脑子转得慢；喜欢 cos、爬山、骑行、唱歌；健身新手，经常把自己弄伤 |
| 脸 | 圆脸，很大的圆眼，深棕色大瞳孔，外眼角略下垂；腮红带几道短斜线（照 Q 版）。眉毛原本偏浓但她不喜欢，画得浅、整齐，大半藏在刘海后面 |
| 头发 | 纯黑长直发到后背中间，蓝黑色光泽、高光带蓝；空气刘海分成几簇尖角，两侧各一缕碎发。礼物榜姿势图和人设图里头发成几大束、轮廓光滑、发梢收拢，不向两边炸开（甲方嫌毛糙）；启动页、登录页保留原来随风散开的飘发 |
| 衣服 | 白色短袖翻领衬衫（泡泡袖）、宽松的黑色无袖针织马甲、红色细领结、黑色百褶裙到膝盖、白色中筒袜、棕色乐福鞋 |
| 徽章 | 右胸（正面看在领结左边），盾形，银边，粉紫色底上一朵白粉玫瑰，照 Q 版 |

## 画风

- **立绘以 SSR 为主**，标准是 `refs/face-s2b.webp` 里的她：干净的线、赛璐璐加柔和的光、头发有光泽、衣褶有明暗。设定图那种平涂只用在人设图上。
- **Q 版就是用户给的 `textures/chibi-sheet.webp`**，不重新设计、不出候选；只按它补全身（`textures/chibi-turnaround.webp`），脸、画风、彩铅质感都照原图，身体约 2 头身：头和下巴以下一样高，腿很短，裙摆接近袜子。桌宠用 Q 版。

## 启动页

人和背景分成两层，叠法照 #343：两层都是 1536×1024，在 Avalonia 里两个 `Image` 叠在一起、都用 `UniformToFill`。

| 项目 | 规格 |
|---|---|
| 背景 | 山上俯瞰河边城市，和原启动页同一个地方；天上是星空和银河，地平线上留一层紫粉到橙色的余晖 |
| 她 | 站在右边约 45%，略朝左，害羞地小幅挥手（左手），右手轻按在胸前，看着镜头 |
| 光 | 头和肩膀背后有一团余晖光晕，从背后给头发勾暖色轮廓；正面是冷蓝的光，头发保持蓝黑光泽 |
| 精灵 | 没有画。她的精灵用图标里的气泡还是另外设计，还没定 |

量过的数（在整张图上取色块算的，算法同 WCAG 对比度）：

| 项目 | 数值 |
|---|---|
| 黑发对身后余晖 | 4.6 : 1。同一片星空没有余晖时只有 1.2 : 1，黑马甲 1.0 : 1；旧看板娘的银发对原夜空是 3.9 : 1 |
| 左上标题、进度条那块天空对白字 | 16.6 : 1 |
| 头顶离上边缘 | 约 18%。1200×720、1600×900、1040×600 三种窗口上下各裁 51、80、68 px，都裁不到 |
| 挥手的指尖离右边缘 | 约 8% |

为什么背景按她画：黑发、黑马甲和原来的深蓝夜空亮度几乎一样，叠上去人会融进夜色；所以保留用户喜欢的星空，在她身后加一团余晖把轮廓托出来。四个方案的对比在 `preview/background-options.webp`。

## 礼物榜姿势图

照原礼物榜两张姿势图的提示词和构图换成她：画布 1024×1536 生成，等比缩到 768×1152；身体在底部一条水平线截断，压在飘带后面；
人水平居中，肩宽约占 46%，下巴约在 52% 高。叠在旧姿势图上头和肩膀几乎重合（`preview/peek-vs-old.webp`），所以礼物榜里精灵停在肩旁、欢呼光芒中心这些坐标可以照用。

| 姿势 | 截断线（占图高，`scene.mjs` 的锚点） | 旧姿势图 |
|---|---|---|
| 平时 `peek-idle` | 0.881 | 0.880 |
| 欢呼 `peek-cheer` | 0.847 | 0.832 |

她身上带一圈冷蓝边缘光，黑发放在暗的直播画面上也看得出轮廓。头发成束往下垂，欢呼时也只占画布约 67% 宽，不向两边炸开。

欢呼的两臂约 26°（离竖直方向），成 V 字。这个画布和比例下约 30° 是上限：再大手会伸出画布，礼物榜上右手也会碰到停在她右肩上方的精灵（现在右手离精灵约 22 px）。要开到 35–40°，得加宽画布、在清单里把她的精灵挪远。

## 精灵

主播要求按一座粉色童话城堡（B 站礼物"浪漫城堡"的截图，不放进仓库）设计。第一版把城堡本身画上窗户眼睛、拱门嘴，像房子长了脸，被否了；改照城堡吉祥物的常见做法（姬路城しろまるひめ戴城堡帽、帕姆穿列车长制服）：先做一个可爱的小生物，城堡只出现在它戴的东西上。

| 部位 | 设计 |
|---|---|
| 身体 | 圆滚滚的奶白色小云朵，带珍珠彩虹光泽，下面拖几缕云尾，飘着；两只短圆手 |
| 脸 | 大圆眼带高光、粉腮红、小猫嘴 |
| 王冠 | 一圈奶白城垛，上面三座玫瑰粉尖塔，中间最高，尖上一面红旗。这是它唯一的城堡特征，也是剪影的记忆点 |
| 胸前 | 红蝴蝶结，结上是她同款的玫瑰盾徽 |

缩到礼物榜上的约 64 px，王冠的三个尖和红旗、大眼睛、红蝴蝶结都还认得出。三张素材是先出平时，再只重画眼睛、用 `tools/sprite-patch.py` 贴回，所以眨眼、看右边除了眼睛逐像素和平时一样。

动作可以按它的设定改：原来礼物榜欢呼时精灵整圈旋转，换成它以后要改，换上她的票里定。

## 拆层

`tools/split.py` 从整张图拆出两层，验证见 `preview/split-overview.webp`、`preview/split-hair.webp`、`preview/login-split.webp`：

- 两层叠回去，正常大小看和整张一样；和整张差超过 24 的像素，启动页约 5%、登录页约 3%，都在她的光晕范围里，那里的星星和光带是补画的。
- 登录页角色层放到深灰底上，左下的光晕边上有一点发黄绿的色斑（取到了树叶），放在她自己的背景上看不出来。
- 角色层放到深灰底和另一片夜空上，发丝完整、颜色正常，没有残影。
- 光晕在角色层里，跟着她走。哪张背景不想要这团光，要再把光晕拆成单独一层，现在没拆。
