# 礼物榜 · 设计包（星夜应援）

2026-11-04 在设计稿画布上定稿（画布是私有的，实现时以本目录为准）。实现任务：[GitHub Issue #296](https://github.com/cyaoc/aether/issues/296)。

礼物榜是网页服务里的一个页面，主播把它加成浏览器素材，叠在直播画面上。没有底板：顶上一条蓝色飘带写“礼物榜”，下面每一名是一张独立悬浮的半透明卡，卡与卡之间透出直播画面。启动页的看板娘站在榜的左下角，气泡精灵飘在她手边。不配声音。

- `boards/GB1-GiftBoard.dc.html`：画板源码。位置、尺寸、颜色、动画时间轴都以这里为准，本文只做导读。画布上的 GB2–GB8 只是用不同参数打开 GB1，见下面的参数表。
- `textures/`：生成后处理过的素材，**直接用，不要重新生成**；来源见 `prompts.md`。
  - `mascot-idle.webp`、`mascot-cheer.webp`：看板娘平时和欢呼两个姿势，透明底。
  - `banner.webp`：标题飘带，图里没有字。
  - `avatars/`：16 个插画头像，**只在画板里当示意**；直播时每一行显示观众自己的头像。
- `lib/`：画板用的字体子集（只含样片用字）。`noto-500-sample.woff2`、`noto-800-sample.woff2` 来自思源黑体（Noto Sans SC，OFL），`playfair-num.woff2` 是 Playfair Display Italic 800 的数字（OFL）。实现时字体要另做大的子集。
- `preview/`：画板截图（一半尺寸），`concept.webp` 是定方向时的概念图，只作参考。
- `tools/`：在本地打开画板的小工具。

## 在本地打开画板

```sh
node docs/design/gift-board/tools/server.mjs 8799
```

然后打开 `http://localhost:8799/render.html?board=GB1-GiftBoard.dc.html&props=<JSON>&freeze=<毫秒>`。PixiJS 和明亮画面的背景图直接用 `entry-animation` 设计包里的文件；礼物图标、大航海头像框和徽章不进仓库，工具按 `tools/blobs.json` 里的 B站 地址现取。截图用 `node docs/design/gift-board/tools/cdp-shot.mjs "<地址>" out.png 5000`。

## 动画

演示里四个事件依次在 1000、3200、5000、7600 ms 发生。下表的时间从事件发生算起，单位 ms。缓动、位移量以画板为准。

| 事件 | 过程 |
|---|---|
| 新上榜 | 0–260 下面的行让出位置；140–300 精灵弹一下；200–640 一颗光胶囊从精灵飞出，划一道 140 px 高的弧落到空位左端；620–860 从左往右展开成这一行，同时一道光扫过；700–900 头像弹出；760–980 昵称从左滑入；820–1020 礼物图标弹出；880–1080 个数弹出；980 起末端闪几颗星光 |
| 个数增加 | 0–320 个数放大到 1.6 倍再回弹；礼物图标跳一下；冒 7 颗星光；精灵眨一下眼 |
| 超车 | 0–320 个数先变；200–800 超上来的一行沿榜右侧一道 26 px 的光弧越上去，背后垫着当前位置形状的底板（卡或胶囊），盖住被超的那一行；被超的行变暗到一半再恢复，顺滑下移；800 起落点闪星光 |
| 新的第一名 | 0–320 个数先变；300–1000 换位，光弧是金色的；900 看板娘换成欢呼并跳 22 px，950–1550 精灵转一圈；900–1650 三道光带绕着第一名卡转圈并收拢；1600–2600 金边亮起、四角星放大、身后一团暖光；1620 起星光炸开；3000–3150 看板娘换回平时 |
| 平时 | 精灵上下飘 ±8 px，每 4.5 秒眨一次眼；看板娘轻微呼吸；第一名的四角星每 3 秒闪一下；其他都不动 |
| 太长时 | 第 4 名起匀速往上滚，滚完一圈空一行再接上，上边 24 px、下边 36 px 渐隐 |

## 实现时注意

- **页面不访问外网，B站 的图除外**：头像、礼物图标、大航海头像框和徽章直接用 B站 图床地址。图床对外站 Referer 返回 403、不带 Referer 返回 200，而且返回 `Access-Control-Allow-Origin: *`，所以加载时设 `referrerPolicy = 'no-referrer'`、`crossOrigin = 'anonymous'`，就能画进 WebGL。加载失败的图不画，不能让页面停住（画板就是这样做的）。
- 大航海头像框是 `roomGiftList` 接口 `global_config.guard_resources` 给的三张 200 px 图，徽章是 `activity-plat/static/20211222/627754775478985e330c25a90ec7baf0/icon-guard{1,2,3}.png`，具体地址见 `tools/blobs.json`；`1` 是总督，`3` 是舰长。
- 遮罩只用带 `-webkit-` 前缀的写法，以直播姬的 CEF 105 为准（同抽奖页）。

## GUI 设置页

画板 `boards/GS1-GiftBoardSettings.dc.html`。照现在真实界面的无头截图画（送礼动画页、通用设置页），主题色、字号和控件都沿用现有设置分区。

| 画面 | props | 画布 | 截图 |
|---|---|---|---|
| 浅色 | `{}` | GS1 | `gui-light.webp` |
| 深色 | `{"dark":true}` | GS2 | `gui-dark.webp` |
| 清空确认 | `{"scene":"清空确认"}` | GS3 | `gui-clear-confirm.webp` |
| 没连直播间 | `{"scene":"没连直播间"}` | GS4 | `gui-offline.webp` |
| 按累计总价 | `{"scene":"按累计总价"}` | GS5 | `gui-total.webp` |
| 最小窗口，礼物榜页没连上 | `{"size":"1040 × 600","scene":"礼物榜页没连上"}` | GS6 | `gui-min-window.webp` |
| 通用设置的页面列表 | `{"page":"通用设置"}` | GS7 | `gui-general-pages.webp` |

- **导航**：放在“送礼动画”下面，图标是奖杯；开着时右边写“开”，关着写“关”。
- **标题栏**：标题、开关、“保存后立即生效”；右边是“清空礼物榜”按钮，垃圾桶图标，红字。没连直播间或榜上没人时不可用；没连直播间时，按钮左边提示“连上直播间后才能清空”。
- **清空**：点了以后底部栏换成“清空后直播画面上的礼物榜也会变空，确定吗？ 取消 清空”，“清空”是红底按钮，做法同抽奖的“结束”。清空后底部栏写“已清空直播间 1768506153 的礼物榜”。
- **礼物榜页状态条**：做法同送礼动画页的视频页状态条。没有推流软件连着时，换成黄色提醒和接入步骤。
- **上榜门槛**：数字框（正整数）加“电池”；下面两个单选，“按礼物单价”和“按累计总价”，各带一行说明。
- **看板娘**：一行标题加说明，开关在右边。
- **右栏“当前榜单”**：只读，顺序和礼物榜页完全一样。每行是名次（斜体数字，前三名金、灰、蓝）、昵称（放不下时省略号）、礼物 × 个数，以及这一行的价值（电池）。右上角写“共 N 位”。没有内容时按情况提示：没连直播间、礼物榜关着、还没有人上榜。
- **通用设置**：网页服务的页面列表在视频页、抽奖页后面加“礼物榜页 · 送礼观众的排行”，连接状态和复制按钮同另外两个页面。
- 最小窗口 1040×600 下，固定文字都不折行；黄色提醒里的接入步骤允许折行，同现有页面。
