# 礼物榜 · 设计包（星夜应援）

2026-11-04 在设计稿画布上定稿（画布是私有的，实现时以本目录为准）。实现任务：[GitHub Issue #296](https://github.com/cyaoc/aether/issues/296)。

礼物榜是网页服务里的一个页面，主播把它加成浏览器素材，叠在直播画面上。没有底板：顶上一条蓝色飘带写“礼物榜”，下面每一名是一张独立悬浮的半透明卡，卡与卡之间透出直播画面。启动页的看板娘从飘带后面探出上半身，气泡精灵飘在她肩旁。只有新的第一名出现时响一声柔和的星光，其余时刻都不出声。

- `boards/GB1-GiftBoard.dc.html`：礼物榜页的画板源码。位置、尺寸、颜色、动画时间轴都以这里为准，本文只做导读。画布上的 GB2–GB8 只是用不同参数打开 GB1，见下面的参数表。
- `boards/GS1-GiftBoardSettings.dc.html`：GUI 设置页的画板，见最后一节。
- 看板娘默认显示，主播可以关掉；关掉后她的位置用来多放几行礼物。
- `textures/`：生成后处理过的素材，**直接用，不要重新生成**；来源见 `prompts.md`。
  - `mascot-peek-idle.webp`、`mascot-peek-cheer.webp`：看板娘平时和欢呼两个姿势，透明底，两张同一张画布、同一比例。
  - `banner.webp`：标题飘带，图里没有字。
  - `avatars/`：16 个插画头像，**只在画板里当示意**；直播时每一行显示观众自己的头像。
- `lib/`：画板用的字体子集（只含样片用字）。`noto-500-sample.woff2`、`noto-800-sample.woff2` 来自思源黑体（Noto Sans SC，OFL），`playfair-num.woff2` 是 Playfair Display Italic 800 的数字（OFL）。实现时字体要另做大的子集。
- `preview/`：直播画面截图是一半尺寸，GUI 截图是原尺寸；`concept.webp` 是定方向时的概念图，只作参考。
- `audio/`：新的第一名那一声，`sources/578803__nomiqbomi__sparkle.mp3`，打包进软件；`events.json` 是试听用的时间点。见“声音”一节。
- `tools/`：在本地打开画板的小工具。

## 一个组件，适应不同的直播画面

礼物榜页**只有礼物榜本身那么大**，不铺满整个直播画面。放左边、放右边、竖屏放在哪里，都由主播在推流软件里摆放；页面从来不猜自己在直播画面的哪个位置，只按页面自己的宽高排版。画板里的 `env` 就是把同一个组件摆进不同的直播画面，组件本身不知道这件事。

| 规则 | 做法 |
|---|---|
| 推荐尺寸 | 浏览器素材 480 × 1000：横屏 1080p 下看板娘、前三名加 6 行正好放下 |
| 宽度决定缩放 | 以 480 宽为设计宽度，按页面宽度等比缩放：素材设成 600 宽，整张榜放大 1.25 倍（竖屏示例） |
| 高度决定行数 | 缩放后的设计高度减去上面的部分，能放几行胶囊就放几行；放不下时第 4 名起循环滚动 |
| 看板娘 | 默认显示，占飘带上方 220 的高度。主播关掉后，榜单上移到顶上留 8，腾出的高度全部用来放行：480 × 1000 从前三名加 6 行变成加 9 行 |
| 最矮 | 设计高度最少 820（看板娘、飘带、前三名和 3 行），关掉看板娘时最少 608；页面更矮时改按高度缩放，整张榜等比缩小并水平居中，例如显示看板娘时 480 × 640 缩到 0.78 倍，关掉时不缩 |
| 特效不出界 | 所有光效、星光、光弧都画在组件范围内，组件之外什么都不画；放在哪里都不会被裁掉，也不会盖到直播内容上 |
| 不做 | 宽比高大的横条（比如画面底部一长条）不在这次范围内 |

## 动画

演示里四个事件依次在 1000、3200、5000、7600 ms 发生。下表的时间从事件发生算起，单位 ms。缓动、位移量以画板为准。

| 事件 | 过程 |
|---|---|
| 新上榜 | 0–260 下面的行让出位置；140–300 精灵弹一下；200–640 一颗光胶囊从精灵飞出，划一道弧落到空位左端；620–860 从左往右展开成这一行，同时一道光扫过；700–900 头像弹出；760–980 昵称从左滑入；820–1020 礼物图标弹出；880–1080 个数弹出；980 起末端闪几颗星光 |
| 个数增加 | 0–320 个数放大到 1.6 倍再回弹；礼物图标跳一下；冒 7 颗星光；精灵眨一下眼 |
| 超车 | 0–320 个数先变；200–800 超上来的一行向右微微让出 14 px 越上去，沿榜右侧留一道光，背后垫着当前位置形状的底板（卡或胶囊），盖住被超的那一行；被超的行变暗到一半再恢复，顺滑下移；800 起落点闪星光 |
| 新的第一名 | 0–320 个数先变；300–1000 换位，光是金色的；900 看板娘换成欢呼并上跳 10 px，950–1550 精灵转一圈；900–1650 三道光带绕着第一名卡转圈并收拢；1600–2600 金边亮起、四角星放大、身后一团暖光；1620 起星光炸开；3000–3150 看板娘换回平时 |
| 欢呼时头顶 | 用飘带上方的空位：880–3100 看板娘身后 14 道暖色光芒慢慢转，中间一团光晕；950–3250 从飘带后面往上抛 70 片彩带和星星（金、白、蓝、粉、浅蓝），落回去时淡出；950–1350 一道光从左到右扫过飘带；950–1750 精灵身边绕一圈 6 颗星光。全部画在组件里。关掉看板娘时没有这块空位，光芒、彩带和精灵的星光圈都不放，飘带扫光和第一名卡的特效照常 |
| 平时 | 精灵上下飘，每 4.5 秒眨一次眼；看板娘轻微呼吸；第一名的四角星每 3 秒闪一下；其他都不动 |
| 太长时 | 第 4 名起匀速往上滚；播事件动画时先停住（画板没演示，页面要做） |

## 声音

只在新的第一名出现时响一声，其余时刻（新上榜、个数增加、超车、太长滚动）都不出声，免得喧宾夺主。

- **素材**：Freesound 上 nomiqbomi 的 [Sparkle](https://freesound.org/people/nomiqbomi/sounds/578803/)（CC0，已打开页面确认，署名不是必须的），原文件放在 `audio/sources/`，**直接用，不要换**。
- **时间点**：最响的点对准新第一名事件开始后 950 ms，也就是看板娘换成欢呼、彩带抛出来的那一帧。关掉看板娘时照样在这一刻响，正好是三道光带开始绕第一名转的时候。用完整的声音，不截短、不预混。
- **怎么播**：照视频页的做法，用 `video/animations/audio.mjs` 的 `prepareCues` 和 `AudioTrack`，由页面自己的动画时钟按帧触发，提前按输出延迟安排；`events.json` 里的写法（`t`、`peak`）和它一致，`peak` 是 −12 dB。
- **音量**：`gift_board.volume`，0 到 100，默认 60，0 时不响。GUI 用拉杆调，和动画音量是同一个控件。
- 页面刚连上时画出来的第一份状态不播动画，也就不响。不和视频页的声音互相避让：同一份大礼物的送礼动画要等一轮送完、停手 3 秒后才播，那时这一声早已响完。

本地试听：`http://localhost:8799/render.html?board=GB1-GiftBoard.dc.html&sound=cheer`，点左上角“点这里带声音播放”，再勾上声音，下一轮循环生效；新的第一名在每轮第 7.6 秒。

试过没选的（都是 Freesound CC0）：LilMati 的 Sparkling Star 01（462095）、Fupicat 的 Congrats（607207）、xkeril 的 Victory (short sting)（706753）、Stevedrums 的 Group_Yay_Cheer（393402）。人群欢呼被否；另外三个也可以，最后选了更柔和的 Sparkle。

## 实现时注意

- **页面不访问外网，B站 的图除外**：头像、礼物图标、大航海头像框和徽章直接用 B站 图床地址。图床对外站 Referer 返回 403、不带 Referer 返回 200，而且返回 `Access-Control-Allow-Origin: *`，所以加载时设 `referrerPolicy = 'no-referrer'`、`crossOrigin = 'anonymous'`，就能画进 WebGL。加载失败的图不画，不能让页面停住（画板就是这样做的）。页面不要像画板那样等所有图都加载完才开始画。
- 大航海头像框是 `roomGiftList` 接口 `global_config.guard_resources` 给的三张 200 px 图，徽章是 `activity-plat/static/20211222/627754775478985e330c25a90ec7baf0/icon-guard{1,2,3}.png`，具体地址见 `tools/blobs.json`；`1` 是总督，`3` 是舰长。
- 遮罩只用带 `-webkit-` 前缀的写法，以直播姬的 CEF 105 为准（同抽奖页）。

- **导航**：放在“送礼动画”下面，图标是奖杯；开着时右边写“开”，关着写“关”。
- **标题栏**：标题、开关、“保存后立即生效”；右边是“恢复上一期”和“清空礼物榜”两个按钮。“恢复上一期”是普通灰框按钮，回退箭头图标，没连直播间或没有上一期时不可用；“清空礼物榜”是垃圾桶图标、红字，没连直播间或榜上没人时不可用。没连直播间时，按钮左边提示“连上直播间后才能清空和恢复”。
- **清空**：点了以后底部栏换成“清空后直播画面上的礼物榜也会变空，确定吗？ 取消 清空”，“清空”是红底按钮，做法同抽奖的“结束”。清空后底部栏写“已清空直播间 1768506153 的礼物榜”。
- **恢复上一期**：点了以后底部栏换成“上一期（11月3日，4 位）会合并回来，确定吗？ 取消 恢复”，当前这一期是空的（例如刚清空）时写“会恢复回来”；“恢复”是主色按钮。恢复后同一观众同一礼物个数相加（龍騰雲海的告白气球 ×5 加上一期 ×3 成了 ×8），底部栏写“已恢复上一期”。
- **礼物榜页状态条**：做法同送礼动画页的视频页状态条。没有推流软件连着时，换成黄色提醒和接入步骤。
- **上榜门槛**：数字框（正整数）加“电池”；下面两个单选，“按礼物单价”和“按累计总价”，各带一行说明。
- **每场开播换新榜**：放在门槛下面、看板娘上面，一行标题加说明“直播跨天也还是同一张；关掉后，只在点“清空礼物榜”时换”，开关在右边，默认开。
- **看板娘**：一行标题加说明“从标题飘带后面探出来主持；关掉后，她的位置能多放 3 行”，开关在右边，默认开。
