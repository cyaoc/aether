依据

  • 设计技能（ui-ux-pro-max）：库里只有界面风格，没有二次元画风条目，所以画风按她的原图定；用上的是它的动效规则：每个画面只让一两样主角元素动，装饰不长期循环。
  • Gacha pull reveal color culture：低档冷而静、中档变暖、最高档金色、彩虹或洗白画面；颜色先于结果出来。
  • 鸣潮抽卡颜色指示：颜色直接对应最高稀有度，是可信的信号。
  • How to create 2D game art、Consistent art style：特效、界面和角色共用视觉语言；描边粗细、颜色、软硬写成规则。
  • Outlines using color：描边用物体本身颜色的深色。
  • Clip Studio 闪亮眼睛画法：星光加一层模糊叠加发光，只留一颗最亮。
  • Sparkling eyes：キラキラ（持续闪）和キラッ（一闪）的区别，四角星是二次元的标准形。
  • 腾讯云直播礼物、礼物飞向主播的专利：直播间按价值分面板、弹幕、全屏几种形式；小礼物只做不打扰别人的飞入。
  • Animated spritesheets：同一动作的帧在同一张图里出、带上定稿的角色图，大小事后缩放救不回来。
