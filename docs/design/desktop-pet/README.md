# 桌宠

直播画面一角的 Q 版看板娘和她的精灵，按直播间里发生的事表演，配气泡和台词，给观众和主播提供情绪价值。
地图和已定的框架在 [#343](https://github.com/cyaoc/aether/issues/343)；角色素材在 `docs/design/mascot/`。本文是演出设计的完整版本，
2026-11-08 在对话里定下，图还没出，出图和画板按文末"流程"走。

## 1. 基本

| 项目 | 规格 |
|---|---|
| 形式 | 网页服务里的一个页面，主播加成浏览器素材，透明底；只在 GUI 版有 |
| 推荐尺寸 | 480 × 540，按城堡演出要用整个页面估的，画板上实测再定 |
| 她 | 当前角色的 Q 版：脸、画风、彩铅质感照 `mascot/textures/chibi-sheet.webp`，身体照 `chibi-turnaround.webp`，约 2 头身；站在页面下方正中，平时约 250 px 高（1080p） |
| 精灵 | 当前角色的精灵（`mascot/textures/sprite-*.webp`），飘在她身旁，规则同 `mascot/README.md` 的"精灵和她的位置关系"：脸低于她的下巴、离她四分之一到半个头、全身露出、约为她头高的一半 |
| 朝向 | 一律正面或略侧向镜头，放左下角、右下角都能用，不做镜像 |
| 气泡 | 代码画，见第 7 节 |
| 一位角色要准备的 | 第 8 节的全部动作表、精灵动作、城堡和大航海的道具，加第 7 节的台词，都放在角色文件夹里；代码只认姿势名和事件，不认是谁 |

## 2. 档位和优先级

**一件事只演一段，按最具体的那一类算：**

| 收到的事 | 演哪一段 |
|---|---|
| 开通或续费大航海 | 舰长、提督、总督之一，不再算大礼物 |
| 城堡礼物（直接送，或盲盒开出） | 城堡演出，不再算大礼物或盲盒 |
| 盲盒 | 开出城堡→城堡；开出的礼物至少是盒子价格的 2 倍→盲盒开大；开出的比盒子便宜→盲盒开亏；其余照开出的礼物算大礼物或普通礼物 |
| 其他礼物 | 单笔达到门槛（默认 1000 电池）→大礼物，否则→普通礼物 |
| 这一笔让礼物榜换了第一名 | 主演出结束后接一段"新的第一名"，不单独再演 |

**分档：**

| 档 | 演出 | 正在演别的时候来了它 |
|---|---|---|
| S | 总督、城堡 | 打断 A 档及以下；同档排队，永远不丢 |
| A | 提督、大礼物、抽奖 | 打断 B 档及以下；同档排队，最多排 3 个 |
| B | 舰长、盲盒开大 | 打断 C 档及以下；同档排队，最多排 3 个 |
| C | 普通礼物、进场、连着送礼、盲盒开亏 | 打断 D 档；正忙就丢掉 |
| D | 心情、日常小动作 | 随时被打断，不排队 |

- 被打断的那段直接结束，不补演。
- 同一个人连着送同一种礼物，合成一段，台词里的个数是合计。
- 抽奖跟着抽奖的进度走：被 S 档打断后，S 档演完回到抽奖当前的状态（还在开奖就继续"期待"）。

## 3. 事件演出

时长是估的，画板上调。"她"一列是依次换的姿势，名字对应第 8 节的动作表；"效果"由代码画。

| 事件 | 档 | 她 | 精灵 | 效果 | 台词 | 时长 |
|---|---|---|---|---|---|---|
| 进场 | C | 挥手 | 挥小旗 | — | 进场 | 1.5 秒 |
| 普通礼物 | C | 鞠躬 | 点头 | 一颗小爱心 | 普通礼物 | 2 秒 |
| 连着送礼（30 秒内收到 5 份以上） | C | 害羞捂脸 | 开心 | 几颗爱心 | 连着送 | 2 秒 |
| 盲盒开亏 | C | 摇盲盒 → 打开盲盒（不冒光）→ 鼓腮跺脚 | 抱头 | 一缕灰烟 | 盲盒开亏 | 2.5 秒 |
| 舰长 | B | 舰长敬礼（戴水手帽） | 戴水手帽敬礼 | 气泡和小锚往上飘 | 舰长 | 3 秒 |
| 盲盒开大 | B | 摇盲盒 → 打开盲盒冒光 → 惊讶 → 欢呼 | 惊讶 → 开心 | 盒里射出光柱、星星 | 盲盒开大 | 4 秒 |
| 大礼物 | A | 捧大礼物盒 → 欢呼 | 开心，绕她飞一圈 | 彩带、星星 | 大礼物 | 3 秒 |
| 提督 | A | 一闪换装 → 提督举望远镜 → 提督敬礼 | 戴水手帽敬礼 | 换装闪光、海鸥、浪花 | 提督 | 4 秒 |
| 总督 | S | 大船从页面一侧开进 → 一闪换装站上船头 → 总督指向前方 → 总督挥手 → 船开走、换回 | 站在桅杆顶挥小旗 | 换装闪光、礼炮、金色彩带、浪花 | 总督 | 6 秒 |
| 城堡 | S | 见第 5 节 | 变回原型城堡 | 见第 5 节 | 城堡 | 10 秒 |
| 新的第一名（追加段） | 跟主演出 | 扶着王冠比 V | 捧王冠飞到她头顶放下 | 王冠落下时一圈金光 | 新的第一名 | 2.5 秒 |

大航海三档逐级升级：舰长只换一顶帽子加一个动作；提督换整套衣服加一个道具；总督换衣服、加大道具，场面最大。

## 4. 抽奖

两种抽奖共用一套反应；揭晓按档次分三种。开奖特效播放时她一直"期待"，等抽奖页揭晓、特效收尾后再做反应，不抢抽奖页的戏
（要查 `LotteryController` 推给页面的状态里能不能知道特效什么时候收尾，不能就按各套主题的时长算）。

| 时机 | 报名抽奖 | 奖池抽奖 | 她 | 台词 |
|---|---|---|---|---|
| 主播新开一场 | ✓ | ✓ | 宣布 | 报名抽奖开场／奖池抽奖开场 |
| 报名截止 | ✓ | | 期待 | 报名截止 |
| 主播点名一位观众 | | ✓ | 点名 | 奖池点名 |
| 转动、开奖特效中 | ✓ | ✓ | 期待 | 奖池转动（奖池抽奖） |
| 揭晓·大奖 | ✓ | ✓ | 欢呼；精灵开心 | 揭晓·大奖 |
| 揭晓·二奖 | ✓ | ✓ | 鼓掌 | 揭晓·二奖 |
| 揭晓·三奖 | ✓ | ✓ | 笑着点头 | 揭晓·三奖 |
| 没人报名就结束 | ✓ | | 失落 | 没人报名 |

## 5. 城堡演出（S 档，约 10 秒）

精灵的原型就是一座立在云上的童话城堡：它王冠的放大版，奶白城垛、三座粉尖塔、红旗，带彩虹。我们自己设计，不照抄礼物美术。

| 时间 | 画面 |
|---|---|
| 0–1.5 秒 | 精灵浑身发光，飞到她身后、放大，交叉淡入成城堡（门关着），升到页面上半部 |
| 1.5–3 秒 | 她转圈变身：闪光里换成公主装（她的衣服改成粉白公主裙，冠冕上是同样的三座尖塔） |
| 3–4.5 秒 | 屈膝礼，气泡说城堡台词 |
| 4.5–7.5 秒 | 转身背对镜头走向城堡：背面走路两帧交替，代码让她越走越小、往上移，像走进远处 |
| 7.5–9 秒 | 城门打开、透出光，她在门口回头挥手，气泡"欢迎来到我的城堡～" |
| 9–10 秒 | 城堡缩回成精灵，她闪光换回平时的衣服，回到原位 |

## 6. 心情和日常（D 档）

没有事件时，她按冷场时长换心情。计时从上一次有礼物算起，"犯困"从上一次有任何事件算起。

| 心情 | 条件（默认） | 她 | 精灵 | 台词 |
|---|---|---|---|---|
| 开心 | 最近 1 分钟内有 3 件以上事件 | 待机，代码让她轻轻蹦；偶尔哼歌 | 绕着她转 | 不说 |
| 平静 | 其他时候 | 待机；每隔 20–40 秒随机做一个日常小动作 | 在旁边飘 | 日常 |
| 无聊 | 15 分钟没有礼物 | 托腮发呆 | 打哈欠 | 无聊 |
| 沮丧 | 40 分钟没有礼物 | 蹲着画圈圈 | 摸摸她的头 | 沮丧 |
| 犯困 | 60 分钟什么事件都没有 | 打瞌睡 | 睡觉，靠着她 | 不说，代码画 Z |

- 日常小动作：举哑铃、哼歌（代码画音符）、爬山（原地迈步）、骑车（代码让车上下颠），随机选一个。
- 每个日常小动作有 1/4 的几率出点事，出事以后接"贴创可贴"，她本来就是经常把自己弄伤的健身新手：

  | 小动作 | 出的事 | 台词 |
  |---|---|---|
  | 举哑铃 | 砸到脚：单脚跳、抱着脚、泪目 | 日常·砸到脚 |
  | 哼歌 | 唱破音：捂着嘴、脸通红 | 日常·破音 |
  | 爬山 | 脚下一滑，摔了个屁股墩，坐在地上揉 | 日常·摔屁股墩 |
  | 骑车 | 车把一歪连人带车摔倒 | 日常·骑车摔倒 |
  | 打瞌睡（犯困时） | 头一点磕到膝盖，惊醒 | 冷场后来了人 |

  打瞌睡磕到头只演"惊醒"，不贴创可贴，演完接着睡。
- 冷场后来了事件：心情是沮丧或犯困时，先演"惊醒"，说"冷场后来了人"的台词，再接这件事的演出。

## 7. 气泡和台词

**气泡**：代码画，圆角白底、粉色描边，一条小尾巴指向她，出现在她头顶一侧；每段演出最多一个气泡，跟着演出出现和消失。
字体、字号、最长多少字、长昵称怎么截断，在画板上实测再定。

**台词**：

- 每类准备几句，每次随机选一句，同一类不连着重复同一句。
- 只填 `{昵称}`、`{礼物}`、`{个数}`、`{关键字}`、`{奖项}`、`{奖品}`；后三个是主播自己填的。不念弹幕原文。
- 台词跟着角色走，写在角色清单里；下面是现在这位的，口吻是社恐、有点结巴、天然呆。

## 8. 素材

**生图规则**（#343）：codex 一张图 3 × 2 共 6 格，每格约 512 × 512，透明底；同一比例，脚底踩在同一条线上（坐着的是屁股在线上），
格子之间留空、全身在格子里；每张第一格固定是待机，当尺子统一各张比例；图里只画人和她手里的道具，Z、音符、星星、汗滴、
彩带、光、气泡都由代码画。切图给 `docs/design/entry-animation/tools/process.py` 加按格切的模式，量出脚底点、头顶点写进清单。

**她的动作表：**

| 表 | 六格 |
|---|---|
| 1 常用 | 待机、挥手、鞠躬、欢呼、惊讶、打瞌睡 |

## 9. 流程

每一步的图都先给用户看，确认了才往下走。

1. 她的动作表 1–6，每张出两次挑一张。
2. 精灵动作 1、2。
3. 城堡设定图 → 公主装设定图 → 动作表 7。
4. 大航海服装设定图 → 动作表 8 → 大船。
5. 在设计稿画布上画角落演出的画板：平时、心情、每个事件、两种抽奖、城堡和总督的整段，定页面尺寸、气泡样式和时长。
6. 素材、画板源码、截图放进本目录，拆票（#343 的角色框架和迁移排在最前）。
