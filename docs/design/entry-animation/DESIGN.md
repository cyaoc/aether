# 进场动画 · 设计总纲

2026-10-26 按最新的讨论整理，同日做完 40 档后补进动作链和直线斩痕，10-27 做完 50 档后补进档位的出刀要求和斩铁沿全长刀痕。规则和实现边界见 [#267 进场动画](https://github.com/cyaoc/aether/issues/267)、[#268 隐藏款](https://github.com/cyaoc/aether/issues/268)；为什么这么做见 [调查记录](../../research/2026-10-25-entry-animation.md)、[ADR 0009](../../adr/0009-hidden-variants-by-spend-not-chance.md)、[ADR 0010](../../adr/0010-entry-animation-rendered-with-webgl.md)。已经定稿的是一般人 30 档（`boards/EV1-EntrySlice.dc.html`）、40 档（`boards/EV2-EntryTriple.dc.html`）和 50 档（`boards/EV3-EntrySwallow.dc.html`），参数见 [README](README.md)，其余都按本文去设计。**动手前先读 [WORKFLOW.md](WORKFLOW.md)**：制作步骤和交付前的自查清单。

## 一、一句话

有资格的观众进场时，**主角**代表这位观众放一记大招：先在画面上认出是谁，再出招、命中、斩开天空，最后用刀光斩出他的昵称。大航海身份决定主角是哪个**流派**；粉丝团等级决定是哪一档**招式**，档越高招式越强。

## 二、总原则（几轮反馈得来，优先级从高到低）

1. **高潮是主角自己的动作，特效只是结果。** 次元斩（主角一闪就到终点，看不到出刀）和第一版总督（只抬手，剑自己飞）都因为"特效多、动作少"被否。每一档、每个身份，最强的那一下必须是主角亲手打出来的。
2. **每个特效都要由动作引起。** 先斩，才有冲击、裂开、名字；不加自己乱动的装饰（第一版的色带、圆环、称号牌各动各的，被评价幼稚）。
3. **动作要连贯，刀光从刀上出来。** 排成动作链：每张姿势是上一张的结果、下一张的起点；每一刀都有预备、拖影帧、收招。刀光沿拖影帧里画出的拖影走，终点落在收招图的刀尖，命中点、火花、冲击波都在刀尖（40 档第一版只有收招图，被评“动作和刀光对不上、人物动作也没逻辑”）。
4. **刀光是弧，斩痕是直线。** 悬在空中的刀痕和天空裂开的线，取命中时还亮着那段刀光的弦，贯穿天空；弧度大的刀光让尾巴在挥刀途中追上来，命中时只剩近乎直的一段（弧线斩痕被评“用力不均”）。斩铁时天空就沿这些刀痕裂开，每条都是全长，不裁掉半截、不另画；镜头跟刀动得多的档，斩铁前要把镜头带回能看到刀痕交汇处、和出刀时同样远近的位置（50 档第一版只裂了半截、交汇处被黑边挡住，被评“最后裂开的是和之前斩击无关的线”）。
5. **节奏要有落差**：静、蓄、爆、停、余韵。全程同一速度就没有冲击力。
5.1 **主角始终面向对手，对手始终在画里；最高档要有危险感**：60 档第二版慢走入场、背对月亮连斩，被评“太装了……没有一点紧张刺激感”。终结技是一路进攻，主角不退、不硬扛。人体和握刀要真实，招式要夸张：第三版做成地面的剑道套路，被评“太写实了就没有了华丽感和冲击感”，50 档有空中动作，60 档的空间和规模都要超过它。
6. **克制**：以黑、白和光为主，每个身份只留一个主色；不铺大块饱和色，不用卡通闪电、描边圆环、箭羽标签这类图形，也不用圆润的字体。
7. **从头到尾认得出是谁**：切入时先出登场字幕，出招后再斩出大号昵称。
8. **斩开的东西后面要有东西**：天空被斩开后露出身份色的里世界，不能直接露出空荡荡的直播画面。60 档相反：里世界开场就铺满，被击破的是它，后面露出现实世界的白天；现实世界完整、不被切开，用亮的蓝天白云和阳光和血月世界分开。
9. **主角不露脸，不用观众头像**：背影或逆光，脸藏在阴影里，谁都能代入；头像画风五花八门，会和画风冲突。
10. **闪光安全**：冲击帧一次最多两帧，不用大面积红色闪光（WCAG 2.3.1；星铁希儿大招被抱怨晃眼）。

## 三、分镜骨架（所有档、所有身份共用）

以一般人 30 档样片为准（一轮约 6.6 秒，时间为实际毫秒）。高档在这个骨架上换招式、加段落。

| 拍 | 样片时间 | 做什么 | 要点 |
|---|---|---|---|
| 压暗 | 0–300 | 上下黑边合进来，直播画面压暗（径向暗角） | 一进来就有电影感 |
| 切入 | 250–520 | 主角带残影冲进画面，站定 | 快进快停 |
| 登场字幕 | 420–2060 | 昵称在脚边从左往右显出 | 让观众先知道是谁；出招时被刀风扫掉 |
| 蓄力 | 520–1950 | 换成蓄势姿势；光点往兵器收；背景淡入；镜头慢慢推近、轻微倾斜；兵器上一道闪光 | 预备动作，越长越有张力 |
| 出招 | 1950–2034 | 拖影帧两帧，刀光沿画出的拖影扫过；换成收招图，刀光的头停在刀尖；镜头猛推 | 最快的一下 |
| 白闪 | 2034–2080 | 一帧白屏 | 只一帧 |
| 冲击帧 | 2080–2160 | 白底黑线 + 黑剪影、黑底白线 + 白剪影各一帧；此时关掉所有滤镜 | 干净的黑白漫画分镜 |
| 顿帧 | 2080–2200 | 画面停住约 0.12 秒，只有震屏在动 | 打实了的感觉 |
| 余波 | 2200 起 | 冲击波扭曲、放射模糊、色散；火花沿刀光甩出；刀光碎成丝；一道直线刀痕悬在空中发光（在主角身后） | 爆发后的余震 |
| 亮名 | 2380–2950 | 大号昵称顺着刀光切出来，带残影；拉出细线和小标签 | 不用放大回弹那种可爱的动法 |
| 收刀 | 2700 起 | 站起身收刀，刀身滑回鞘里，碰鞘一闪；余烬飘起；镜头缓缓推近 | 动作的收尾；碰鞘之后天空才裂开 |
| 斩铁 | 3000–3950 | 天空沿直线刀痕裂开：有月亮的那块顺切面滑走、倾落，另一块反向轻移；切口发光，余烬从两边剥落 | 斩开有独立的一拍；多刀时先按出刀顺序各亮一下 |
| 里世界 | 3000–5000 | 同一片天空的身份色版本从缝里露出，完整显现，停一拍，再退回直播画面 | 斩开的是"表面"，露出主角的力量 |
| 收 | 6180–6600 | 主角、昵称淡出，黑边退开 | |

## 四、档位梯子：每升一档，招式升一级（以一般人为例）

每升一档，出刀次数和节奏落差都要超过下一档；空中、滞空这类高光段落里必须出刀，不能只摆姿势。连斩的间隔越来越短，最后一击前的预备停得最久（God of War 的连招节奏；绝区零雅、崩铁黄泉的大招都是“连斩 → 停顿 → 终结一击”）。50 档第一版是上挑 → 倒悬滞空 0.3 秒 → 落斩，空中一刀没出、出刀比 40 档还少，被评“起招直接收招、配不上 50 级”，倒立在没有对手的场景里也多余。

| 档 | 招式 | 主角动作 | 新增的机制 | 时长 |
|---|---|---|---|---|
| 30 | 一闪 | 贴地蓄力，踏地一闪穿过画面，站起收刀，碰鞘后天空沿刀痕滑开，露出血月 | 基准（样片） | 约 6.5 秒 |
| 40 | 三连斩 | 冲刺 → 拔刀横斩 → 回身上撩 → 刀过头顶 → 双手重劈 → 站起收刀 | 连招：三刀各一次顿帧，节奏"哒、哒、轰"，最重的一刀放最后；镜头跟着刀抬起、甩下；三条直线刀痕，天空碎成几块各自滑落 | 约 7.5 秒 |
| 50 | 飞燕五连 | 低身起势 → 上挑升空 → 燕返折回 → 回旋横扫 → 同一圈上撩 → 刀在头后滞空 → 全力落斩，单膝落地 → 站起收刀 | 空中连斩：五刀五次顿帧，节奏「哒 —— 哒哒哒 ——（停）—— 轰」；落地双重冲击波；收刀前镜头退到能同时看到全身和刀痕交汇处，天空沿五道全长刀痕碎开 | 约 8.5 秒 |
| 60 | 飞天斩月 | 低身蓄力开界 → 冲天拔斩 → 回旋横斩 → 车轮斩 → 贯日突 → 螺旋升空 → 残影齐斩 → 滞空纳刀、法相升起 → 和法相同一帧贯穿月亮 → 急停 → 拍刀 → 世界炸开 | 终结技：七刀，三组冲击帧，从地面杀到月亮，残影齐斩，法相，连血月一起斩开，拍刀炸碎血月世界，露出完整的蓝天白云 | 约 10 秒 |

总督每档多约 0.5 秒（称号牌先盖章）。30–50 档可以复用下一档的姿势；60 档是终结技，冲击力、爆发力、华丽度都要全系列最高，而且靠身体动作撑起来，不能只靠特效，也不复用低档的动作（用户：“重复感官不好”）。不是同一招上堆粒子。

姿势张数由动作链决定，在描述阶段定。图里不画拖影，一刀通常是挥到一半和收招两张，刀光由画板画。已定的：30 档 5 张（贴地蓄力、踏地拔刀、急停、收刀中、收刀定格）；40 档 9 张，收刀复用 30 档；50 档 11 张，都是全身图，收刀复用 30 档；60 档 18 张，法相 4 张。

**法相的规则**：一般人、舰长、提督 60 档的法相只放大主角自己的动作，主角拔刀它拔刀、主角斩它斩，不单独出手。总督不用法相，巨剑握在他自己手里。

## 六、动作设计

- **关键姿势**：每个姿势一张图，用 codex 以该身份的亮相图作参考生成，保证是同一个人、同一套装备（提示词见 `prompts.md`）。每个身份至少 5 个基础姿势：亮相、蓄势、出招（拖影帧）、斩后、残心；再按档加招式姿势，见第四节。
- **动作链**：连招先排链，每张姿势写清身体和刀从哪到哪；生图时把链上前后相邻的姿势一起作参考，动作才接得上。收招图要接上拖影帧的末端，对不上就以拖影帧为参考生成去掉拖影的同一姿势。
- **节奏**：平时一张画停三帧（一拍三），出招、命中那几下每帧都换（一拍一）；位置和镜头的平滑移动按两帧一跳，保留动画感。
- **拖影帧**：出招那一下直接用画成拖影的姿势图（动作本身拉长、变形），只停两帧。
- **残影**：切入和挥刀时拖两道身份色残影，透明度 0.32、0.16。
- **对齐**：30 档按"躯干在图宽的位置"对齐到同一个 x，图底贴画面底；40 档起按胯部对齐（胯在原图的位置加缩放），头到胯的长度一致，图底渐隐，镜头可以上下甩。50 档起人要离地、地面要入画，姿势用全身图；拖影帧按刀尖对到收招图的刀尖上。
- **人体**：两只手都在身前，不能绕到身后握刀或甩到身后（50 档两张图手背到身后，被评“不符合人体结构”）。
- **握刀的手和朝向**：主角惯用右手，刀挂左胯，四档开场都是人物在左，从左往右面向前方的月亮；之后月亮的位置随人物动作变化，人物和月亮的结束位置、朝向都按动作设计，不固定。图不镜像。朝右一律画纯侧面，胸口不转向镜头：离镜头近的是右半身，刀鞘在远侧，腰后只露鞘尾；手要握鞘时左手在腹前，看得见前臂和四个指尖，不能画成“背后拿刀鞘”。朝右时胸口一转向镜头，两条胳膊就要交叉才能握对，模型会画成左右手相反。朝左可以转向镜头。刀身、刀鞘都是笔直的。写法见 prompts.md。
- **收尾**：刀镡碰鞘之后天空才裂开。30、40、50 档都是站起身正常收刀，用同一组姿势；60 档空中拍刀。站起后不再蹲下，上举的招式放中间，不放最后。一闪全程脚踩在地上，飞起来的拔刀留给 60 档。
- **动作设计**：招式接近现实，可以为冲击力做艺术加工，衔接一定要自然：上一招收招的刀位、重心、速度方向就是下一招的起点，不重新摆架势；同一档相邻的刀不重复方向；每一档的起手式都不一样。
- **握法按招式定**，不能全部双手握刀：

  | 招式 | 握法 | 左手 |
  |---|---|---|
  | 拔刀一击 | 右手单手 | 握鞘，同时把刀鞘往后拉 |
  | 回旋横扫、螺旋斩 | 右手单手，换攻击距离 | 往反方向伸开，保持平衡，手握拳 |
  | 重劈、上撩、落斩 | 双手 | 握柄尾 |
  | 突刺 | 双手 | 握柄尾 |
  | 甩刀、残心 | 右手单手 | 回到鞘口 |
  | 居合架势、纳刀 | 右手握柄 | 握鞘口，紧贴护手，拇指抵住护手 |
- **生图注意**：明确写"四周留边"，否则人物容易被切在图边；碰边时把那一侧渐隐。

## 七、特效

- **渲染**：视频页里用 WebGL（PixiJS 8 + pixi-filters 6，打包进软件，ADR 0010）。
- **刀光**：不用静态图片。沿一条弧线画月牙，分三层：外晕、刀身、白芯；内侧边缘锐利、外侧柔和；尾部按长度渐隐；刀身里有几条速度细线；外侧跟一道细的副刃。命中后变细、碎成丝。
- **滤镜**：辉光一直开（冲击帧时关）；顿帧松开后才起冲击波扭曲（约 0.5 秒）、放射模糊（约 0.3 秒）和色散（约 0.5 秒）。昵称和字幕单独一层，不参与辉光和扭曲。
- **粒子**：蓄力时光点往兵器收；命中时火花沿刀痕两侧甩出；斩铁时余烬从切口两边剥落；残心时余烬缓缓上飘。
- **背景**：月夜等背景用整张图，按直线刀痕切开（多刀时切成几块），顺切面滑走、加速，像被切开的东西滑落；后面垫同构图的身份色里世界。60 档以下的刀痕不能穿过月亮：30、40 档把月夜左右翻过来，月亮在左上方主角身后；50 档月亮在空中几刀的左边。斩铁时天空沿出刀留下的刀痕全长裂开，镜头动得多的档在斩铁前把镜头带回能看到刀痕交汇处、和出刀时同样远近的位置。
- 具体参数见 [README](README.md) 的滤镜表和样片源码。

## 八、打击感要点

研究结论：顿帧、声音、镜头三样缺一样，打击感就明显变差。

1. **预备动作**：蓄力姿势、光点收拢、兵器上一道闪光，让观众知道"要来了"。
2. **顿帧**：命中时画面停约 0.12 秒，所有动画的时间都冻住，只有震屏按实际时间走。连招每一下都要有自己的顿帧（40 档三次）。
3. **冲击帧**：命中那一刻黑白反相各一帧，带主角剪影和集中线；最多两帧。
4. **镜头**：蓄力慢推（约 7%），出招猛推（到 1.12 倍），顿帧后沿刀的方向大震，再慢慢回落。
5. **爆发后的余波**：扭曲、放射模糊、色散都很短，只在顿帧之后出现。
6. **收势**：站起收刀、碰鞘、斩铁，让动作有结尾，而不是突然停住。
7. **声音**（实现时配）：蓄力低鸣、起手（拔刀）、斩击、顿帧时一声重低音、甩刀、天空裂开、余音。主播可调音量或关掉。

## 九、文字和称号

- **全程只显示粉丝名**：不显示「粉丝团 LV.xx」，也不写招式名，没有细线和小标签。
- **登场字幕**：霞鹜文楷（LXGW WenKai）52 px，字距 8，笔画加粗 1.6 px。
- **大号昵称**：霞鹜文楷 132 px，字距 16，笔画加粗 4 px，跟着刀痕略微倾斜；顺着刀光从左往右切出，带两层身份色残影。亮天空上（60 档收尾）加一层柔和的深色阴影。
- **称号牌**：舰长、提督、总督写身份；总督亮名前先盖章，昵称换金色渐变。
- **字体**：B站昵称有中文、日文、英文，要用一款字体统一显示：霞鹜文楷 Medium（OFL），简体、繁体、日文汉字、假名、英文都覆盖（实测 GB2312、Big5 一级、JIS X 0208、假名、ASCII 全收）。原始文件约 26 MB，实现时做子集。韩文等不支持的字回退系统字体。昵称放不下就缩字号，不截断。
- **隐藏款**：称号牌旁加「限定 · 款名」，不显示剩余天数。
