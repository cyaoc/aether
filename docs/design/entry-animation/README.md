# 进场动画 · 设计包（一般人 30、40、50、60 档）

**设计总纲见 [DESIGN.md](DESIGN.md)**：原则、分镜骨架、档位梯子、四个流派的招式、动作、特效、打击感都在那里。**动手做新的一档前先读 [WORKFLOW.md](WORKFLOW.md)**：步骤和交付前的自查清单。本文只讲已经做出来的画板。

画板画在设计稿画布上（画布是私有的，实现时以本目录为准）。规格：[#267 进场动画](https://github.com/cyaoc/aether/issues/267)、[#268 隐藏款](https://github.com/cyaoc/aether/issues/268)。已定稿：

- **EV1 一般人 30 档「一闪」**：贴地蓄力，踏地一闪穿过画面，急停，站起收刀，碰鞘后天空沿一道直线刀痕裂开。
- **EV2 一般人 40 档「三连斩」**：冲刺拔刀横斩，回身上撩，刀过头顶换双手，重劈收尾，站起收刀，三道刀痕。
- **EV3 一般人 50 档「飞燕五连」**：上挑升空，燕返，横扫，上撩，滞空，全力落斩，单膝落地，站起收刀，五道刀痕。
- **EV4 一般人 60 档「飞天斩月」**：冲天拔斩，回旋横斩，车轮斩，贯日突，螺旋升空，残影齐斩，法相升起，和法相同一帧贯穿血月，拍刀炸开血月世界，露出蓝天白云。

2026-10-31 四档按设定图全部重画：主角一律右手握刀，不镜像；开场人物在左，从左往右面向月亮；图里不画拖影，刀光全部由画板画；全程只显示粉丝名，字体统一用霞鹜文楷；主角在屏幕上的大小四档一致。舰长、提督、总督以及隐藏款都还没出画板。

- `boards/`：画板源码。时间轴、位置、尺寸、滤镜参数以这里为准，本文只做导读。画板里的 `/_blob/<id>` 对应哪个文件见 `tools/blobs.json`。
- `textures/`：codex 生成后处理过的素材，**直接用，不要重新生成**；提示词见 `prompts.md`。
- `lib/`：画板用的 PixiJS 8.12.0、pixi-filters 6.1.4（都是 MIT），以及只含样片用字和 ASCII 的昵称字体子集（霞鹜文楷 LXGW WenKai，OFL）。实现时字体要另做大的子集。
- `preview/ev1/` 到 `preview/ev4/`：四张画板各拍的截图（一半尺寸）。
- `tools/`：在本地打开、截图画板的小工具。

## 在本地打开画板

```sh
node docs/design/entry-animation/tools/server.mjs 8795
```

浏览器打开 `http://localhost:8795/render.html?board=<画板文件>&props=<JSON>&freeze=<毫秒>`，画板文件是 `EV1-EntrySlice.dc.html`、`EV2-EntryTriple.dc.html` 或 `EV3-EntrySwallow.dc.html`。`props` 是画板的 data-props：`pause`（定格到某一拍）、`speed`（1 倍 / 0.5 倍 / 0.25 倍）、`room`（示意画面 / 浅色房间 / 深色房间 / 透明）。`freeze` 把时钟钉在那个毫秒。

截图要用 `node docs/design/entry-animation/tools/cdp-shot.mjs "<上面的地址>" out.png 5000`：WebGL 画板一直在渲染，`chrome --headless --screenshot` 等不到空闲，截不出来。一次只截一张，几个 Chrome 同时跑会钉不住时钟。

人物图用 `tools/gen.sh` 生成，每张现行图的提示词和参考图在 `tools/prompts-final.json`。模型画不准刀，生成后用 `tools/paste-blade.py` 把 `textures/blade.webp`（从武器设定图抠下来的刀身）贴到每张图上，刀身世界长度统一约 370 px。生图后的处理用 `tools/process.py`（裁到不透明区域、发光图转白色加透明、边缘渐隐、背景压成 WebP；需要 Pillow 和 NumPy）。上传到画布后，把新 blob id 和文件对应写进 `tools/blobs.json`。

**设定图**：`sheet-hero*`（主角 10 个机位，有刀和空鞘各一份）、`sheet-oni*`（法相）、`sheet-sword*`（武器）。所有人物图都以它们为参考。`blade.webp` 是从武器设定图切出的刀身。

刀光的控制点是在姿势图上量出的刀尖位置（见画板源码），换任何一张姿势图都要重新量。

**图和画板的约定**

- 图里只有人物，不画拖影和特效。出鞘的图用 `tools/paste-blade.py` 按刀柄方向重贴设定图的刀身；压在身体上的刀保留原画，用 `tools/shorten-hilt.py` 收短。
- 比例拿护手直径当尺子：刀柄约 2 倍，刀身约 6.27 倍。用 `tools/sword-axis.py` 量折角，超过 4° 不合格。
- 主角在屏幕上的大小四档一致：护手直径约 56 px，全身约 700 px。只有 60 档的残影齐斩、法相亮相、飞天一闪这类全景镜头例外。
- 主角贴图 tint `0xe0e0e0`，辉光阈值 0.9，这样刀光发光，白外套不糊。

## 规则

- 每个特效都由主角的动作引起；刀光沿刀尖的路径由画板画，终点是收招图的刀尖，命中点、火花、冲击波都在刀尖。
- 刀光（挥刀轨迹）是弧，刀斩开的痕迹是直线。
- 斩铁时天空就沿出刀留下的刀痕裂开，每条都是全长，不裁、不另画。
- 冲击帧一次最多两帧，不用大面积红色闪光。
- 主角不露脸，不用观众头像。
- 一般人的主色是红（#FF3B4E 一类）；舰长蓝、提督紫、总督金配黑，沿用 B站 的颜色。
- 斩开的天空后面要有东西：同一片天空按身份色画的里世界（一般人血月；舰长、提督、总督待画），不能直接露出直播画面。
- 从切入起就要能认出是谁：登场字幕先出，出招后大号昵称再斩出来。

## 画布上的其他画板

画布上「进场动画 · 大招登场」两行（EN1–EN6、EH1–EH2）是第一版，用户评价是人物没动作、太幼稚、特效廉价、冲击力差，已经被 EV1、EV2 取代；里面的身份、档次规则和隐藏款「赛博夜行」的构想仍然有效，画面不要照搬。
