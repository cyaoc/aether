# 进场动画 · 样片（一般人 60 档）

2026-10-25 在设计稿画布上做出样片 EV1（画布是私有的，实现时以本目录为准）。样片定了新方案的做法：主角真的出招，节奏有压暗、蓄力、出招、顿帧、余波、亮名、残心，特效用 WebGL 渲染。样片还有几处小瑕疵待讨论，改完就地更新本目录。舰长、提督、总督，30 到 50 档，以及隐藏款，都还没按这个做法出画板。

- `boards/`：画板源码。时间轴、位置、尺寸、滤镜参数以这里为准，本文只做导读。画板里的 `/_blob/<id>` 对应哪个文件见 `tools/blobs.json`。
- `textures/`：codex 生成后处理过的素材，**直接用，不要重新生成**；提示词见 `prompts.md`。
- `lib/`：画板用的 PixiJS 8.12.0、pixi-filters 6.1.4（都是 MIT），以及只含样片用字的字体子集（Noto Serif SC Black、Barlow Condensed，都是 OFL）。实现时字体要另做大的子集。
- `preview/`：样片各拍的截图（一半尺寸，示意画面背景）。
- `tools/`：在本地打开、截图画板的小工具。

## 在本地打开画板

```sh
node docs/design/entry-animation/tools/server.mjs 8795
```

浏览器打开 `http://localhost:8795/render.html?board=EV1-EntrySlice.dc.html&props=<JSON>&freeze=<毫秒>`。`props` 是画板的 data-props：`pause`（播放 / 蓄力 / 出招 / 冲击帧 / 余波 / 亮名 / 残心）、`speed`（1 倍 / 0.5 倍 / 0.25 倍）、`room`（示意画面 / 浅色房间 / 深色房间 / 透明）。`freeze` 把时钟钉在那个毫秒。

截图要用 `node docs/design/entry-animation/tools/cdp-shot.mjs "<上面的地址>" out.png 5000`：WebGL 画板一直在渲染，`chrome --headless --screenshot` 等不到空闲，截不出来。

## 时间轴（一轮 7.6 秒，动画本身约 6.6 秒）

时间是实际毫秒。2080–2200 是顿帧：画面停住，只有震屏和冲击帧按实际时间走；顿帧之后的动画时刻都往后推 120 ms。

| 毫秒 | 拍 | 画面 |
|---|---|---|
| 0–300 | 压暗 | 上下黑边合进来（高 118），直播画面压暗（径向暗角） |
| 250–520 | 切入 | 亮相姿势带两道红色残影从左边冲进来 |
| 520–1950 | 蓄力 | 换成按刀姿势；月夜背景 600–1250 淡入；红白光点往刀柄 (660, 735) 收；镜头 1 → 1.07 推近、轻微倾斜；1780–1940 刀柄上一道十字闪光 |
| 1950–2034 | 出招 | 拖影姿势两帧；刀光 1960–2060 扫过；镜头猛推到 1.12，小震 |
| 2034–2080 | 白闪 | 一帧白屏（不透明度 0.85） |
| 2080–2160 | 冲击帧 | 白底黑线 + 黑色剪影、黑底白线 + 白色剪影各一帧，此时关掉所有滤镜 |
| 2080–2200 | 顿帧 | 画面停住，刀光停在最亮的样子 |
| 2200 起 | 余波 | 冲击波、放射模糊、色散；大震屏；天空沿刀痕分成上下两半错开散去；火花沿刀痕两侧甩出；刀光碎成丝；刀痕留一条细线到 3000 |
| 2380–2950 | 亮名 | 昵称从左往右切出来，带两层红色残影；细线和红色小方块拉出；「粉丝团 LV.60」淡入 |
| 2900 起 | 残心 | 换成收刀站姿；余烬飘起；镜头缓缓推到 1.025 |
| 6180–6600 | 收 | 主角、昵称、暗角淡出，黑边退开 |

## 刀光、刀痕和名字

- 刀光是一条二次贝塞尔弧：起点 (650, 690)、控制点 (1350, 630)、终点 (2050, 330)，命中点在 (1350, 570)。三层叠加：外晕（宽 2.6 倍，红，0.16）、刀身（宽 78，红，0.8）、白芯（宽 0.34 倍）；内侧边缘锐利、外侧柔和；尾部按长度渐隐；刀身里有 7 条速度细线；外侧 1.35 倍处跟一道细的白色副刃。顿帧后 520 ms 内变细、碎成 9 根丝。
- 刀痕是从 (-300, 934) 到 (2300, 266) 的直线，月夜背景按它分成上下两半，沿法线 (0.249, 0.968) 各错开 170。
- 名字用 Noto Serif SC Black 132 px，字距 26，放在 (1010, 700)，转 -0.12 弧度；不参与辉光和冲击波（单独一层，只跟镜头动）。

## 滤镜

| 滤镜 | 参数 | 什么时候 |
|---|---|---|
| AdvancedBloom | threshold 0.6、bloomScale 1.15、blur 7、quality 5 | 一直开，冲击帧时关 |
| Shockwave | 中心 (1350, 570)、speed 1500、amplitude 46 → 0、wavelength 240、brightness 1.15 | 顿帧结束后 520 ms |
| ZoomBlur | strength 0.15 → 0、中心同上、innerRadius 60 | 顿帧结束后 300 ms |
| RGBSplit | 红、蓝各偏移 11 → 0 px | 顿帧结束后 480 ms |

## 规则

- 每个特效都由主角的动作引起：先有斩击，才有冲击、裂开和名字；不加自己乱动的装饰。
- 冲击帧一次最多两帧，不用大面积红色闪光。
- 主角不露脸，不用观众头像。
- 一般人的主色是红（#FF3B4E 一类）；舰长蓝、提督紫、总督金配黑，沿用 B站 的颜色。

## 画布上的其他画板

画布上「进场动画 · 大招登场」两行（EN1–EN6、EH1–EH2）是第一版，用户评价是人物没动作、太幼稚、特效廉价、冲击力差，已经被这个样片取代；里面的身份、档次规则和隐藏款「赛博夜行」的构想仍然有效，画面不要照搬。
