# 通用设置：两个标签，网页服务的页面改成列表加详情

2026-11-11 在设计稿画布上定稿（画布是私有的，实现时以本目录为准）。通用设置一页放了软件更新、网页服务、日志三节，
网页服务又列了四个页面，每行连地址、宽高和没连上的说明约 80–100 px，内容一共 908 px，默认窗口只看得到 595 px，
最小窗口 475 px，要往下滚；以后每多一个页面还要再高一截。

- `preview/`：按下表改出的原型截的真实界面（无头 Skia）。画布上的 GT1、GT5、GT6、GW1–GW4 就是这几张。
- `prototype.diff`：截图用的原型，基于 `ef9ddf5`。只为截图写，**不能直接套用**：列表样式是从桌宠页复制的、测试没改，
  正式实现照 issue 里的说明。

## 页头

| 项目 | 规格 |
|---|---|
| 标签 | 页头 `HeaderTabs` 放一个 `ListBox.viewTabs`：「网页服务」「更新和日志」，和进场欢迎的标签同一种。默认停在网页服务 |
| 生效时机 | 跟着标签换：网页服务是“端口保存后立即生效”；更新和日志是“日志设置重启后生效；自动更新下次打开时生效” |
| 保存栏 | 两个标签共用一个，和桌宠页的标签一样；在一个标签改了、切到另一个标签，照样显示有未保存的修改 |

## 网页服务标签

上半部分在 `BodyContent`，高度固定（实测 128 px），不随页面数变；下半部分在 `BelowBodyContent`，填满剩下的高度。

| 项目 | 规格 |
|---|---|
| 去掉 | 原来的“网页服务”节标题和它的说明“直播姬里的浏览器素材从这里打开页面”（标签就是标题）；端口下面的“改了端口，直播姬里所有浏览器素材的地址都要跟着改”（改了端口时保存栏本来就说“保存后网页服务换到新端口，直播姬里的地址要跟着改”） |
| 状态卡 | 现有的状态卡（图标、“运行中”、说明）多一列放在最右，垂直居中：`端口` 标签和端口输入框，间距 8。端口的报错和只读提示放进卡里，在说明下面 |
| 列表标题 | 卡下面一行：`页面` 标签，旁边 `caption muted singleLine`：“每个页面在直播姬里各加一个浏览器素材” |
| 两栏 | `Grid` 外边距 `20,0,20,18`，列 `260,*`，列间距 20 |
| 左栏 | 有边框的列表框，和桌宠页左边的分组列表同一套样式：边框 1、圆角 8、内边距 6；每项高 34、内边距 `8,0`、14 号字；选中样式用 `ListBox.nav`。始终有一项选中，默认视频页 |
| 列表项 | 列 `18,*,Auto`，间距 8：页面图标（和原来每行的图标相同）、页面名字（`Texts.Name`）、连接状态（7 px 圆点 + `ConnectionsText`，12 号字，颜色和原来行里的状态相同：连着绿、没连着橙、服务没开灰） |
| 列表滚动 | 放不下时只在框里滚（`web-service-many-pages.webp`） |
| 右栏 | 选中页面的详情，放在 `ScrollViewer` 里，间距 16，从上到下见下表 |

### 右栏：一个页面的详情

| 项目 | 规格 |
|---|---|
| 标题行 | 图标 16（`Accent.Text`）、名字 15 号 SemiBold；最右是连接状态（圆点 + `ConnectionsText`，12 号 SemiBold） |
| 用途 | 标题下面，间距 3，`hint`：视频页“欢迎动画、进场动画和送礼动画在这里播放”，抽奖页“报名、开奖和中奖名单”，礼物榜页“送礼观众的排行”，桌宠页“桌宠在直播画面一角表演” |
| 地址 | `地址` 标签，下面是只读地址框（高 32、13 号等宽字、`Border.Subtle` 底）和“复制”按钮（复制后两秒显示“已复制”，和现在一样） |
| 宽高 | `宽高` 标签，下面是 `secondary` 文字：视频页 `1920 × 1080`，抽奖页 `横屏 1920 × 1080 · 竖屏 1080 × 1920`，礼物榜页 `480 × 1000，可以等比放大`，桌宠页 `480 × 640`。不再有尺寸图标和“各行对齐的一栏” |
| 没连上 | 只在这个页面没有推流软件连着时显示：`Border.notice.warning` 卡，提醒图标 + “还没有推流软件连着。在直播姬里添加浏览器素材，地址和宽高照上面填；已经加过的，右键素材 → 刷新。”，可以折行 |

## 更新和日志标签

| 项目 | 规格 |

## 其他页面

- 视频页、礼物榜页、桌宠页状态栏上的“地址和宽高在通用设置 ›”：点了打开通用设置，切到网页服务标签，并在列表里选中这个状态栏对应的页面（从桌宠页来就选中桌宠页）。
- 状态栏的设置步骤原来说“照通用设置里‘礼物榜页’那一行填”，已经没有行了，改成“照通用设置里的‘礼物榜页’填”，桌宠页同样。

## 实测

无头 Skia 截真实界面，两个标签、页面都没连上和都连上了都量过：

| 窗口 | 改前 | 网页服务标签 | 更新和日志标签 |
|---|---|---|---|
| 1200×720 | 内容 908 px，可视 595 px | 上半 128 px，右栏 449 px 放得下 | 放得下 |
| 1040×600 | 内容 908 px，可视 475 px | 上半 128 px，右栏 329 px 放得下（最高的“没连上”状态） | 放得下 |

列表每多一个页面多 34 px；1040×600 下框里放得下 9 项，再多在框里滚。
