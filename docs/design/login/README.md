# 登录页

2026-11-05 在设计稿画布上定稿（画布是私有的，实现时以本目录为准）。没有登录凭据或 B站说未登录时显示：看板娘插画铺满窗口，
二维码卡片浮在她手机对着的那片天空里。实现任务：[GitHub Issue #313](https://github.com/cyaoc/aether/issues/313)。

- `textures/login.webp`：定稿插画，1536×1024，约 126 KB。**直接用，不要重新生成**；来源见 `prompts.md`。
- `preview/`：按下表写的原型截的真实界面（无头 Skia），三种窗口，浅色深色各一张。画布上的 LG1–LG6 就是这六张。
- `tools/`：生图提示词和脚本，只作来源记录。

## 画面

| 项目 | 规格 |
|---|---|
| 插画 | 铺满窗口，等比放大后居中裁切（Avalonia 是 `Stretch="UniformToFill"`），左右不裁，只裁上下 |
| 底色 | `#0F1550`，和启动页相同，只在插画还没画出来时露出 |
| 主题 | 浅色和深色共用这张插画；二维码卡片跟随主题 |
| 标题 | `Aether`，由界面绘制：左 44、上 56，30 号，粗体，白色，和启动页标题同一位置 |
| 版本号 | 右下角：右 20、下 14，`caption numeric`，白色，不透明度 0.7 |
| 二维码卡片 | 窗口分成两列等宽，卡片在右列水平垂直居中。样式用现有的 `Border.qr`（`Surface.Card` 底、圆角 14、`QrShadow` 阴影），内边距左右 28、上下 24 |
| 卡片内容 | 从上到下，间距 18："扫码登录 B站"（22 号，SemiBold）；二维码区 260×260；"打开 B站 App 扫一扫"（`singleLine secondary`，SemiBold） |
| 二维码区 | 三种状态和现在一样：正在获取二维码…／白底二维码／错误原因和"重试" |
| 其他内容 | 没有。不放功能介绍、介绍句、步骤条和其他提示 |

| 窗口 | 插画显示 | 截图 |
|---|---|---|
| 默认 1200×720 | 上下各裁 51 px（按原图算） | `preview/login-1200x720-*.webp` |

按原图算，人物头顶离上边缘约 225 px，精灵、手机和两只手在 285 到 525 px 之间，三种窗口最多裁 80 px，都裁不到。
右半边是安静的夜空，光带从手机流到右边，从卡片后面穿过。

## 已验证

- 原型按上表写成，`VisualReviewTests.Fixed_text_stays_on_one_line_at_supported_sizes` 在 1200×720、1040×600 浅色深色都通过，`preview/` 就是那次的截图。
- 截图是 macOS 上的无头渲染，不是真实窗口；Windows 上没有验证。
- 1536 宽的图在 Retina 屏和最大化窗口上会被放大，略软，和启动页一样先不处理。
